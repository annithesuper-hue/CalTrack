# Project Environment

- Expo SDK 57.0.x, React Native 0.86, React 19.2, TypeScript strict, Expo Router under `src/app`.
- Package manager: npm. Metro runs on port 8081.
- Start Metro with `npm start`; build the native iOS development app with `node node_modules/expo/bin/cli run:ios`.
- This app requires a development build. RevenueCat, HealthKit, widgets, Live Activities, and Clerk native storage do not run fully in Expo Go.
- iOS and Android folders are generated by Expo CNG and are not source-of-truth.
- Type-check with `node node_modules/typescript/bin/tsc --noEmit`.
- Environment variables: `EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY`, `EXPO_PUBLIC_REVENUECAT_API_KEY_TEST`, and server-only `GEMINI_API_KEY`.
